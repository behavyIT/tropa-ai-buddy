# Change: AI-buddy MVP «Тропа»

## Why
Наставник тратит 40–48 ч за 6-месячную программу (55–65 ч за 9-месячную), заметная часть — повторяющиеся
объяснения и организационные действия. Стажёру сложно понять, что относится к его задачам, какой шаг следующий
и к кому идти; ему неловко «отвлекать» руководителя. Информация разбросана по сервисам.

## What Changes
- ADDED `route` — персональный маршрут по чек-листу Авито с зависимостями и следующим лучшим шагом.
- ADDED `knowledge-qa` — ответы по материалам команды с ACL-фильтрацией и цитатами.
- ADDED `absence`, `access` — действия через корпоративные сервисы (MCP) по схеме «план → подтверждение → квитанция».
- ADDED `mentor-escalation` — вопросы наставнику сводкой, объединение похожих, ответ в базу знаний.
- ADDED `teachback` — приём пунктов «Расскажи о Sentry/Grafana».
- ADDED `proactive`, `insights`, `feature-flags`, `demo`, `web-ui`, `security`, `corporate-mcp`, `platform`.

## Impact
- Новые сервисы: `tropa` (Go API + встроенный UI), `corp-mcp` (имитация корпоративных систем).
- Хранилища: PostgreSQL (состояние, квитанции, события), Redis (лимиты, лидер крона).
