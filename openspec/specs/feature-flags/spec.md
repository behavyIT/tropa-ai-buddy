# feature-flags Specification

## Purpose
Runtime-флаги сценариев с переопределением на команду — постепенный запуск и A/B по командам.

## Requirements

### Requirement: Разрешение и права
Значение SHALL определяться как team → global → default; глобальные флаги меняет HR BP, командные — руководитель своей команды.

#### Scenario: [FLAG-01] Переопределения
- **WHEN** HR BP выключает teach-back глобально, а руководитель включает для своей команды
- **THEN** у его стажёров режим работает, у другой команды — нет; выключение доступов/вопросов меняет поведение агента
