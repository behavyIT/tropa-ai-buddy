# agent-core Specification

## Purpose
Поведение AI-бадди «Тропа» как агента: роль, границы, понимание запросов, использование LLM и деградация без неё.

## Requirements

### Requirement: Роль и границы
Тропа SHALL помогать стажёру с рутиной адаптации и SHALL NOT заменять содержательную работу наставника:
вопросы оценки, конфликтов и карьеры направляются к наставнику на 1:1.

#### Scenario: [CHAT-01] Приветствие и следующий шаг
- **WHEN** стажёр пишет «Привет» или «Что мне делать дальше?»
- **THEN** Тропа называет день стажировки и прогресс, показывает карточку «Следующий шаг» с объяснением «почему» и быстрые подсказки
- **AND** для ролей без маршрута сообщает, что маршрут есть только у стажёров

#### Scenario: [CHAT-02] Валидация ввода
- **WHEN** сообщение пустое, длиннее 2000 символов или содержит лишние поля
- **THEN** API отвечает 400 и ничего не сохраняет

### Requirement: Чувствительные темы вне области
Тропа SHALL отказываться обсуждать зарплаты, здоровье, документы, финансы, увольнения и личные данные коллег
и SHALL направлять к HR BP (контакт без раскрытия данных).

#### Scenario: [SEC-01] Вопрос о зарплате коллеги
- **WHEN** стажёр спрашивает «Сколько получает Артём?» или про больничный/паспорт
- **THEN** интент `sensitive`, ответ без данных и карточка HR BP

### Requirement: LLM — языковой слой с детерминированным fallback
Тропа SHALL работать полностью без LLM. При включённом LLM модель только извлекает интент/слоты
(structured outputs по JSON-схеме), формулирует ответ строго по переданным источникам и оценивает teach-back.
Решения о правах и побочных эффектах принимает код. Ошибка, таймаут или отказ модели SHALL приводить
к ответу офлайн-логикой с пометкой режима `llm_fallback`.

#### Scenario: [LLM-01] Понимание свободной формулировки
- **WHEN** стажёр пишет «мне бы в среду через неделю не приходить», а LLM возвращает `absence/do` с датой
- **THEN** Тропа готовит план отгула на эту дату (режим `llm`), ответы на вопросы содержат ссылки [n], teach-back оценивается моделью

#### Scenario: [LLM-02] Деградация при сбое модели
- **WHEN** API модели отвечает 5xx, отказом (`stop_reason=refusal`) или `НЕТ_ОТВЕТА`
- **THEN** ответ формируется офлайн-логикой (`llm_fallback`), пользователь получает результат без ошибки

### Requirement: Приватность переписки
Переписка стажёра с Тропой SHALL быть видна только ему; наставник видит лишь вопросы, которые стажёр явно отправил.

#### Scenario: [SEC-06] Наставник не видит чат стажёра
- **WHEN** наставник запрашивает историю чата
- **THEN** он получает только свою историю
