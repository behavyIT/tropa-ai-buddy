# platform Specification

## Purpose
Запуск, конфигурация, контент и инфраструктурные компоненты.

## Requirements

### Requirement: Конфигурация и запуск
Приложение SHALL конфигурироваться переменными окружения, валидировать их и корректно останавливаться.

#### Scenario: [APP-01] Бинарник стартует и останавливается
- **WHEN** запускается `tropa`
- **THEN** `/healthz` отвечает, по сигналу — graceful shutdown; неверный конфиг — ошибка

#### Scenario: [APP-02] Конфиг из окружения
- **WHEN** заданы переменные окружения
- **THEN** значения применяются; без `SESSION_SECRET` в прод-режиме и без ключа при `LLM_PROVIDER=anthropic` — ошибка

#### Scenario: [APP-03] Продуктивная топология
- **WHEN** корпоративный MCP-сервер внешний (отдельный процесс, как в Docker Compose), лимиты в Redis
- **THEN** сценарии работают, `/readyz` отражает сбой сервиса (503)
- **AND** в демо-режиме сервис получает симулированное время в заголовке `X-Demo-Now` и принимает отгул на дату из «будущего» демо-календаря, даже если по реальным часам она прошла

#### Scenario: [APP-04] Run и ошибки зависимостей
- **WHEN** приложение запущено с кроном, затем остановлено; БД или Redis-URL неверны
- **THEN** штатная остановка; ошибка старта при недоступных зависимостях

### Requirement: Контент как код
Маршруты, командные паки, тестовые инструкции, рубрики и каталог доступов SHALL валидироваться при старте.

#### Scenario: [CAT-01] Встроенный контент валиден
- **WHEN** загружается контент
- **THEN** 22 пункта backend-маршрута, у каждого документа есть разделы

#### Scenario: [CAT-02] Ошибки ссылочной целостности
- **WHEN** контент ссылается на несуществующие документы, рубрики, системы, зависимости
- **THEN** загрузка падает с перечнем ошибок

#### Scenario: [CAT-03] Ошибки разбора
- **WHEN** нет front matter, битый YAML
- **THEN** ошибка разбора

### Requirement: Офлайн-понимание русского языка
Детерминированный разбор SHALL определять интенты, даты («завтра», «в пятницу», «с 13 по 14 ноября», «13.11») и системы без ложных срабатываний.

#### Scenario: [NLU-01] Интенты и системы
- **WHEN** разбираются типовые фразы
- **THEN** интенты определены верно; «продукт» не распознаётся как «прод»

#### Scenario: [NLU-02] Даты
- **WHEN** разбираются даты в разных формах
- **THEN** получаются корректные даты/диапазоны; несуществующие даты отбрасываются

#### Scenario: [TXT-01] Нормализация текста
- **WHEN** текст нормализуется и стеммится
- **THEN** «ё→е», стоп-слова убраны, усечение по границе предложения

#### Scenario: [CLK-01] Симулированные часы
- **WHEN** время перематывается
- **THEN** день стажировки и рабочие дни считаются корректно

#### Scenario: [WEB-01] Раздача SPA
- **WHEN** запрашивается любой путь интерфейса
- **THEN** отдаётся index.html (SPA fallback), статические файлы — как есть
