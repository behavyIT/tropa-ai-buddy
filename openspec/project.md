# Project Context — «Тропа», AI-buddy для стажёров

## Purpose
Прототип AI-наставника (кейс Avito Start, Hack&Change 2026). Помогает стажёру освоиться в команде:
ведёт по маршруту адаптации, отвечает на вопросы с учётом контекста и прав, выполняет действия
в корпоративных сервисах (через MCP) только после подтверждения, снимает с наставника рутину.

## Tech Stack
- Backend: Go 1.26 (net/http, pgx, go-redis, anthropic-sdk-go), PostgreSQL 16, Redis 7.
- Frontend: React 19 + TypeScript, TanStack Query, Zustand, Zod, Vite.
- Интеграции: MCP (JSON-RPC 2.0, Streamable HTTP) — имитация сервисов отсутствий, доступов, чек-листа, календаря.
- LLM (опционально): Anthropic Claude (`claude-opus-5-5`), structured outputs; детерминированный офлайн-режим по умолчанию.

## Conventions
- Spec-Driven Development: каждое поведение агента описано требованием и сценариями (`#### Scenario: [ID] …`).
  ID сценария обязан встречаться в имени автотеста (`TestABS02_…` в Go или `[UI-07]` в Vitest).
  Проверяется тестом `internal/spectrace` — сценарий без теста роняет CI.
- Права решает код (`internal/policy`), а не LLM. LLM — только «языковой слой» с детерминированным fallback.
- Любой побочный эффект — через жизненный цикл «план → подтверждение → выполнение → квитанция».
- Тестовые инструкции помечаются как тестовые и никогда не выдаются за регламенты Авито.
- Только синтетические данные; сценарии с чувствительными персональными данными и финансами вне области.

## Domain Context
Чек-лист стажёра Авито (вкладки «Материалы для всех», «Чек-лист Backend») стал основой маршрута:
этапы «Первые дни», «Неделя 1», «Недели 2–4», «Месяцы 2–3»; пункты «Расскажи о Sentry/Grafana»
реализованы как teach-back. Роли: стажёр, наставник (buddy), руководитель, HR BP.

## Important Constraints
Покрытие строк прикладного кода > 80%; отклик UI на локальные операции < 1 с; обращения к LLM и
сервисам не блокируют интерфейс, показывают статус ожидания и корректно обрабатывают сбои.
