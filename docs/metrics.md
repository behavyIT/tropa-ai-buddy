# Метрики пользы и проверка эффекта

## Дерево метрик
**North Star — время до самостоятельности стажёра**: дни до первого принятого MR и до закрытия этапа «Недели 2–4».

| Уровень | Метрика | Как считаем (события) | Цель пилота |
|---|---|---|---|
| Нагрузка наставника | Рутинные обращения к наставнику на стажёра в неделю | `question_escalated` + опрос | −40% |
| | Часы наставника за программу | дневник времени + оценка `mentor_minutes_saved` | 40–48 ч → ≤ 32 ч |
| Самостоятельность | Self-serve rate — доля ответов без эскалации | `answer_shown{answerable}` | ≥ 70% |
| | Время ожидания доступов | `access_wait{hours}` | медиана < 8 ч |
| | Просрочки маршрута | `overdue` по маршруту | −50% |
| Качество | Доля 👍 среди оценённых ответов | `answer_feedback` | ≥ 80% |
| | Повторный вопрос после ответа (тот же шаг, < 10 мин) | `chat_turn{step}` | ↓ |
| Безопасность (guardrails) | Утечки по правам | аудит + тесты QA-02/03, SEC-05 | **0** |
| | Доля LLM-ответов с fallback | `chat_turn{mode=llm_fallback}` | < 5% |
| Знания | Опубликованные ответы наставников, закрытые «пробелы» | `mentor_answered{published}`, Тропинки | растёт |

Оценка экономии в UI («Тропинки») — явные допущения: самостоятельный ответ ≈ 7 мин наставника, выполненное действие ≈ 10 мин,
принятый teach-back ≈ 15 мин, объединённый вопрос ≈ 7 мин. Допущения калибруются дневником времени в пилоте.

## Дизайн эксперимента
- **Stepped-wedge по командам через feature flags.** Стажёрские когорты малы, поэтому рандомизация по командам: в каждый
  период включаем Тропу ещё нескольким командам; команды без неё — контроль. Флаги (`actions.*`, `teachback`, `mentor.digest`)
  позволяют включать сценарии по отдельности и измерять вклад каждого.
- **Статистика для малых выборок:** сравнение медиан (Mann–Whitney), бутстреп-доверительные интервалы, учёт команды как кластера.
- **Качественная часть:** короткий опрос стажёров (1 вопрос в неделю: «насколько легко было найти, что делать дальше?»),
  интервью с наставниками на экваторе.
- **Предрегистрация:** метрики и пороги фиксируются до старта; анализ на выпускном когорты.
- **Guardrails:** любая утечка по правам — стоп эксперимента; рост 👎 > 30% — откат флага.

## Как это видно в прототипе
Вкладка «Тропинки» (руководитель, HR BP): KPI-плитки, «где застревают» (плановые дорожки vs протоптанные тропинки),
пробелы базы знаний (без сырых текстов переписки), прогресс стажёров. Синтетическая прошлая когорта помечена и
нужна, чтобы дашборд был показательным в демо.
