# Безопасность и данные

| Угроза | Мера |
|---|---|
| Раскрытие недоступных сведений через ответ или LLM | ACL-фильтрация до поиска; LLM получает только разрешённые фрагменты; тесты QA-02, QA-03 |
| Выполнение операций без прав | Политика в коде на каждом эндпоинте + проверка сервисом по делегированной идентичности (MCP-05, SEC-05) |
| Побочный эффект без согласия | Только «план → подтверждение»; LLM не вызывает инструменты записи (ACT-01) |
| Двойное выполнение | Атомарный переход статуса + ключ идемпотентности (ACT-02) |
| Prompt injection из документов | Источники передаются как данные в тегах `<sources>` с явным запретом исполнять инструкции; действия всё равно требуют подтверждения и проверки прав |
| CSRF | SameSite=Strict cookie + обязательный `X-Requested-With` (SEC-03) |
| XSS | React-рендеринг текста, без `dangerouslySetInnerHTML`; CSP `default-src 'self'` (UI-06) |
| Перебор паролей / злоупотребление чатом | Rate limit: вход 10/мин/IP, чат 30/мин/пользователь, напоминания 1/12 ч |
| Утечка переписки | Чат приватен (SEC-06); наставник видит только отправленный вопрос; в аналитике — только нормализованные термины (INS-02) |
| Чувствительные данные | Зарплаты, здоровье, документы, финансы — отказ и маршрутизация к HR BP (SEC-01) |
| Секреты | Только через переменные окружения; `.env.example` без секретов; `SESSION_SECRET` обязателен при `DEMO_MODE=false` |
| Отказ зависимостей | Таймауты, ретраи только транспортных ошибок, circuit breaker, `/readyz`; LLM → офлайн-fallback |

Данные: только синтетические сотрудники и тестовые инструкции (помечены «Тестовая инструкция — не регламент Авито»).
Пароли — bcrypt; сессии — HS256 JWT на 8 ч. Предлагаемый срок хранения переписки в проде — 90 дней с удалением по запросу.
