# Сценарий демонстрации (≈ 5 минут)

Подготовка: `docker compose up --build`, открыть http://localhost:8080. При необходимости ⋯ → «Сбросить демо».

1. **Вход** — карточка «Алекс Новиков (стажёр Backend)». Слева маршрут по чек-листу Авито, в чате уже утренний бриф: Тропа пишет первой.
2. **«Что мне делать дальше?»** — следующий шаг с объяснением «почему», блок «Ждём: Артём Ким — добавить в чаты» и «Пока ждёшь — сделай».
3. **«Как оформить отгул? Стоит ли отвлекать руководителя?»** — ответ по тестовой инструкции с цитатой. Затем «Оформи отгул на 13 ноября» →
   карточка плана с предупреждением «Демо спринта», правами и согласующим → «Отправить заявку» → квитанция `ABS-…`, статус «На согласовании».
4. **«Запроси стандартные доступы»** → выдано сразу, пункт маршрута закрылся, разблокировались avito-cli и stash.
   **«Дай доступ к проду»** → отказ по правам роли с объяснением. **«Нужен доступ к k8s-staging»** → на согласовании, пункт «ждёт».
5. **«Хочу рассказать про Sentry»** → объяснение → карточка рубрики (что раскрыто, что упущено) → «Засчитать пункт» в чек-листе.
6. **Вопрос вне базы** («Как называть ветки в монорепо фронтенда?») → «это вопрос для человека» → план вопроса наставнику → отправить.
7. **Сменить → Мария (руководитель)** → «Согласования»: согласовать отгул и k8s; «Тропинки»: где застревают стажёры, пробелы базы.
8. **Сменить → Артём (наставник)** → «Сводка вопросов»: ответить и «Сохранить в базу знаний».
9. **Снова Алекс** → в чате ответ наставника; тот же вопрос теперь отвечается карточкой «Артём уже отвечал». Колокольчик: статусы согласований.
10. **⏩ +1 день** → новый бриф, напоминания; **⋯ → «Имитировать сбой сервисов»** → заявка «Не отправлено» с кнопкой «Повторить» — UI не блокируется.
