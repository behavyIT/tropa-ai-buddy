# Проверка качества: факты, а не обещания

| Что проверяем | Результат | Как воспроизвести |
|---|---|---|
| Распознавание интентов офлайн-NLU | см. [nlu-intents.md](nlu-intents.md) | `EVAL_REPORT=1 go test ./internal/nlu -run EVAL01` |
| Ответ по верному источнику / честное «не знаю» | см. [kb-answers.md](kb-answers.md) | `EVAL_REPORT=1 go test ./internal/app -run EVAL02` (нужен PostgreSQL) |
| Время отклика локальных операций | см. [latency.md](latency.md) | `python3 scripts/eval/latency.py` (нужен запущенный стенд) |
| Сценарии из спецификаций | 100% сценариев привязаны к автотестам | [../../openspec/TRACEABILITY.md](../../openspec/TRACEABILITY.md) |
| Покрытие кода | Go и Web выше 80% | [../../coverage/summary.md](../../coverage/summary.md) |
| Сквозной путь в браузере | e2e Playwright, видео записано этим прогоном | `web/e2e/demo.spec.ts` |

Оба золотых набора использовались и при настройке — это регрессионные, а не слепые тесты.
Слепая проверка качества ответов — на пилоте (см. [../metrics.md](../metrics.md)).

## Что меняли по результатам замеров

| Что пробовали | Что получили | Что выбрали |
|---|---|---|

| + бонус «документ про это»: доля IDF слов запроса в заголовке | 16/16, ни одного нового промаха | оставили |
| Шаблон «что делать» → интент «что дальше» | «Что делать, если долго нет ревью?» уходило в маршрут | исключение для «если/когда/чтобы/почему» |
| Совпадение алиасов систем подстрокой | «продукт» распознавался как «прод» (доступ к production) | точное совпадение токена, префикс — только для явных `*`-алиасов |
